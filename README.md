# BIOLOGY X — آکادمی تعاملی علوم نهم

یک وب‌سایت فارسی، راست‌چین و سازگار با موبایل برای یادگیری مباحث زیستی علوم پایه نهم.

## امکانات نسخهٔ اول
- پنج بخش آموزشی: گوناگونی جانداران، دنیای گیاهان، جانوران بی‌مهره، جانوران مهره‌دار و با هم زیستن
- توضیحات مفهومی و بخش‌های «فراتر از کتاب»
- آزمایشگاه مجازی آموزشی دربارهٔ اسمز
- آزمون تعاملی با بازخورد و امتیاز
- واژه‌نامهٔ قابل جست‌وجو
- ذخیرهٔ پیشرفت درس‌ها در مرورگر
- طراحی واکنش‌گرا و رابط فارسی

## انتشار
فایل اصلی سایت `index.html` است. گردش‌کار GitHub Actions در `.github/workflows/pages.yml` برای انتشار خودکار آماده شده است. در صورت نیاز از مسیر **Settings → Pages**، منبع انتشار را روی **GitHub Actions** قرار دهید و وضعیت اجرا را در زبانهٔ **Actions** ببینید.

مطالب تکمیلی با عنوان «فراتر از کتاب» از توضیحات اصلی جدا شده‌اند. این سایت ابزار کمک‌آموزشی است و جایگزین متن کتاب درسی نیست.
